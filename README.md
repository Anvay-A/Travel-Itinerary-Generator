# Travel-Itinerary-Generator
Planning a trip can be overwhelming and time consuming. This AI-powered notebook builds personalized, day-by-day travel itineraries based on your preferences like duration, budget etc, using Generative AI.

Used Gemini 2.0 Flash API

# GenAI Capabilities Used :
1. Few-shot Prompting – use this for guiding Gemini with examples
2. Structured Output (JSON) – clean, structured output for easy understanding
3. Embeddings (Simulated) – match your interests, budget with attractions

All the code is written in Google Colab for easy accessebility and to easily access the API.
